# 受控实验：`versions/<v>/src/` 到底怎么参与编译

> 目的：核实 `10-阶段0-探针结论.md` 里「`versions/<v>/src` 同名文件无法覆盖共享 `src/`」这条结论的**真实成因**。
> 该结论是 U4（物理隔离机制三选一）的唯一依据，成因不同则结论完全不同，因此单独做受控实验。

## 一、上一轮的原始现象

副 agent 报告：共享 `src/client/java/areahint/VersionProbeMarker.java` 与 `versions/1.21.1/src/client/java/areahint/VersionProbeMarker.java` 同名同路径时，
`& .\gradlew.bat :1.20.4:build` 失败：

```
J:\mc\mods\src\client\java\areahint\VersionProbeMarker.java:7: 错误: 类重复: areahint.VersionProbeMarker
* What went wrong:
Execution failed for task ':1.20.4:compileClientJava'.
```

上一轮把它解释为「版本目录无法覆盖共享目录」。**该解释不完整**：报错发生在编译 **1.20.4** 时，而冲突文件在 **1.21.1** 的目录里。

## 二、受控实验设计与结果

### 实验 1：把标记类放进**未声明**的版本目录

- 前置状态：`settings.gradle` 的活跃列表为 `versions '1.20.4', '1.21.1'`，**1.20.1 不在列表内**（只有注释）。
- 动作：新建 `versions/1.20.1/src/main/java/areahint/MountProbeMarker.java`，只放在这一个位置，**共享 `src/` 里没有同名类**。
- 命令：`& .\gradlew.bat :1.20.4:compileJava :1.20.4:compileClientJava --console=plain`
- 结果：**退出码 0**，`BUILD SUCCESSFUL in 6s`；`:1.20.4:compileJava` 与 `:1.20.4:compileClientJava` 均为 `UP-TO-DATE`。
- 结论：**未声明为节点的版本目录不参与任何编译**（连挂载都不会发生）。

### 实验 2：删除标记类后强制重编，确认基线干净

- 动作：删除上述标记类 → `& .\gradlew.bat :1.20.4:clean :1.20.4:compileJava :1.20.4:compileClientJava --console=plain`
- 结果：**退出码 0**，`BUILD SUCCESSFUL in 9s`，`4 actionable tasks: 4 executed`（确实重新编译了）。
- 产物：`versions/1.20.4/build/classes/java/main` **85 个 class**、`.../client` **299 个 class**，与基线规模一致。
- 全仓库已无 `*MountProbeMarker*` 残留，`git status --short src` 为空。

## 三、机制结论（两次实验 + 上一轮现象合起来才能解释）

| 情况 | 结果 |
|---|---|
| 版本目录属于**已声明节点**，且与共享 `src/` **有同名同路径类** | `错误: 类重复`（上一轮现象） |
| 版本目录属于**未声明节点** | 完全不参与编译（实验 1） |
| 版本目录与共享 `src/` **无同名类**（新增不同 FQN） | 正常编译并进入该节点产物 |

**正确表述**：

1. Stonecutter 把**已声明节点**的 `versions/<v>/src/...` 一起纳入编译（因此 1.21.1 目录里的类会与 1.20.4 的共享源码同场竞技）；
2. 它**没有**提供"后写覆盖先写"的语义——同名即冲突，不是覆盖；
3. 因此该目录的能力是**追加**：只能放共享 `src/` 中不存在的新类（不同 FQN），或配合显式 `setSrcDirs` 做整体替换。

> 上一轮报告里"版本目录覆盖共享目录不成立"这个**结论方向是对的**，但"因为不覆盖所以冲突"的因果说反了：冲突的原因是**两个目录同时进入同一个 javac**，而不是覆盖失败。

## 四、对 U4（物理隔离机制）的影响

| 方案 | 是否可行 | 说明 |
|---|---|---|
| (a) 同名覆盖共享 `src/` | **不可行** | 直接 `错误: 类重复`，已实测 |
| (a') 共享 `src/` 留接口 + 版本目录放**不同 FQN** 实现 | **可行** | 无同名冲突；选择器在共享侧用一处条件注释或工厂完成 |
| (b) 对该节点显式 `setSrcDirs` 整体替换 | **可行** | 1.21.1 空骨架已用此法跑通；代价是该节点完全脱离共享 `src/` |
| (c) `//? if` 条件注释 | **可行** | 适合 ≤3 行小差异；密度过高会让共享源码变成翻译表 |

**建议**：默认走 **(a')**（与 NetworkCompat 的"接口在共享侧、实现按代际"设计天然吻合），仅在某个节点需要彻底换掉整套源集时才用 (b)。
