# Fabric 1.21.5 适配执行计划

**目标：** 将 1.21.5 加入完整构建目标，保留当前域名功能，并保持已有五版本可构建。

**架构：** 共享代码保留几何生成、域名规则和相机相对坐标。世界边界沿用各节点的 BufferCompat 隔离状态与 GPU 提交；地图覆盖层使用共享纯接口/门面及每节点同名工厂，旧后端与 1.21.5 的 RenderPipeline / RenderPass 实现均放在版本目录。共享侧只保留机械 API 改名的小分支，不引入通用渲染框架。

**技术栈：** Java 21、Fabric、Yarn 1.21.5、Stonecutter、Gradle。

## 执行顺序

1. 核对实际 1.21.5 游戏及 Xaero 依赖中的渲染接口；临时激活目标并记录当前源码的编译断点。
2. 并行实现世界边界绘制与地图覆盖层的新管线提交；明确帧缓冲目标、深度、透明混合、裁剪和资源释放语义。
3. 补齐 1.21.5 的 VizEditXaeroBridge 及初始化调用，核实对应 Xaero 字段和接口。
4. 修复其余共享客户端、服务端 API 差异；条件分支遵循既有 Stonecutter 写法。
5. 独立审查后构建全部六个目标，检查最终 JAR 的入口、Mixin、依赖范围和必要类；更新版本说明。

## 分工与验证约束

- 所有修改直接在 main；保留已有 AGENTS.md 和宣传文档的用户改动。
- 不新增测试，不运行游戏；通过 Gradle 编译、成品字节码及依赖 API 检查验证。游戏画面与联机效果留待用户验收。
- 仅主代理执行 Gradle，避免多个构建同时操作共享生成目录。
- 本轮不扩展 1.21.8、1.21.11 或 26.x。
