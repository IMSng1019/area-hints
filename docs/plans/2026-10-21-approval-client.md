# 审批客户端实现计划

**目标：** 实现配置同步、审批与回复面板，以及可恢复的临时域名预览和顶点编辑。

**架构：** `approval` 客户端管理器持有连接状态、服务器快照和唯一草稿会话；列表与详情界面只发送审批动作；边界管理器合并内存预览。正式域名数据仍仅由已有同步协议更新。

**技术：** Java 17、Fabric 网络兼容层、Gson、Minecraft Screen。

1. 为 addhint/deletehint 增加副本回调模式，保持现有普通提交路径。
2. 为 BoundViz 增加按维度替换的临时域名覆盖；按键长按优先恢复审批会话。
3. 实现分包快照接收、正式目录配置/回复持久化、断线清理、草稿和结果状态机。
4. 实现滚动申请列表、详情、意见历史分页、打回编辑入口和受限操作按钮。
5. 注册初始化、世界目录就绪回调和特殊指令；列出所有新增翻译键。
6. 按用户要求不新增测试、不提交，由主代理统一编译验证。
