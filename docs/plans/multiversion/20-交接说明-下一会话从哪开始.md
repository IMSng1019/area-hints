## 六、已知的坑（都是实测踩过的，别再踩）

| 坑 | 现象 | 处理 |
|---|---|---|
| Stonecutter 版本与 Gradle 不匹配 | `Stonecutter requires at least Gradle 9` | 0.8.0+ 必须 Gradle ≥ 9；本仓库先升 Wrapper 再用 0.9.7 |
| 版本目录同名类 | `错误: 类重复: areahint.XxxYyy` | 机制 ②：不同 FQN，或整体 `setSrcDirs` 替换 |
| `jar { from("LICENSE") }` | 产物少一条 `LICENSE_areas-hint` | 必须写 `from(rootProject.file("LICENSE"))`（已修） |
| 手写 `stonecutter.gradle` | `Could not get unknown property 'stonecutter'` | 该文件由插件自动生成，不要手写 |
| 第三方依赖跨版本沿用 | 编译过、运行时加载失败（ModMenu 9.2.0 声明 `minecraft >=1.20.3`） | D2：按版本解析 |
| 版本节点缓存进 Git | `versions/<v>/.gradle/` 未被忽略 | `.gitignore` 已补 `versions/*/.gradle/`；`build/` 不带斜杠本就匹配任意层级 |
| 根项目不再产出 jar | 以为构建坏了 | 根项目在 Stonecutter 下是 tree；用 `:1.20.4:build`，产物在 `versions/1.20.4/build/libs/` |
