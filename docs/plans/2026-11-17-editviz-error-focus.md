# editviz 连笔几何修复与错误定位实施计划

**目标：** 修复连续笔画触发的遗漏几何错误，定位截图中的不连通问题，并在保存或简化失败后将画布移到可定位的几何错误处。

**架构：** 沿用双源码树、Java2D 几何、现有草稿历史和 `VizEditCanvas.frame` 画布接口。几何定位独立于游戏界面，客户端会话保存一次性定位请求和错误标记；不改变草稿或提交权限。网格与全部 Xaero 版本共用定位逻辑。

**技术：** Java 17/21/25、JUnit 5、Fabric 12 个活跃版本、现有翻译 JSON。

## 已有证据

- 运行中的 Minecraft 1.20.1 使用 `L:\.minecraft`；其 mods 中的 4.8.5 JAR 不含上轮填充和边界笔修复，SHA-256 与工作区修复包不同。原文件名与版本号相同造成交付歧义，本次构建使用明确的修复版本标记。
- 用户新截图显示边界笔、笔宽 4、“层岩巨渊”草稿，以及 `geometry_disconnected` 提示；截图无法排除小孤岛或退化轮廓。
- 当前源码可用两笔整数采样复现新增洞：宽 4 的 `(68,41)、(75,63)、(88,69)、(79,73)、(81,68)`，填充并松手优化后，宽 1 的 `(74,63)、(71,75)、(81,64)`。第二笔填充外环重新正规化会再次分出约 1/6 平方格的小洞。
- 不连通误报的独立复现：合法三角形 `(-4.3,3.2)、(-24.2,-17.6)、(9.2,-28.3)`，边界笔宽 6，依次绘制 `(-6,7)、(-9,-2)`，会留下交点与旧顶点之间的往返线，被错误计作第二个区域。

## 实施与验证

1. 将两笔完整生命周期写入两套 `VizEditGeometryTest`，先确认失败，再修复外环重建后仍出现新洞的情况；完整保留真实旧洞，不以面积容差删除轮廓。
2. 单独复现边界笔不连通问题，区分真实孤岛与严格退化的往返线。仅对数学上无面积的退化表示做清理，保留真实微小区域和点接触的分离区域。
3. 新增纯几何 `GeometryIssueLocator` 与回归测试，支持洞、额外分离轮廓和自交的定位。不存在对应空间问题时返回无位置，不伪造坐标。
4. 两套会话和界面接入一次性定位请求；保存失败、手动简化失败时显示原错误并定位。绘制拖动期间不强制移动镜头，以免鼠标世界坐标改变正在进行的笔画；完成手势后处理定位。
5. 重用 `VizEditCanvas.frame`：网格取景到完整问题轮廓；Xaero 保持当前缩放、平移到真实红色标记点，避免凹轮廓包围盒中心落在外部。草稿变化或撤销后清除旧标记，窗口重建和切换画布保持有效位置。
6. 若增加位置提示，11 种翻译均使用对应语言更新，不缩减翻译文件。
7. 执行独立 Java 17/21/25 回归、UI/画布定位测试、翻译检查、12 个版本完整构建和独立审查；在 main 提交。当前运行游戏的未保存草稿不强制关闭或覆盖。

## 产品行为

可定位的几何错误会把视图移到问题轮廓并给出红色标记及 X/Z 坐标。保存／简化仍保留严格校验，真正不连通的区域需要用户连接或去掉额外区域。网络、权限、属性等非空间错误保持文字提示。

## 实现与独立验证结果

- 外环重建后继续处理本次新增洞，再恢复原有洞交集；用路径段类型和坐标精确位值检测循环，不设固定轮数或面积阈值。遇到重复路径保留原始笔画，继续由保存校验明确报告问题。
- `AreaContours` 仅移除严格无损简化后不足三个点的退化路径。正常轮廓发现非共线点后直接保留，不为每次渲染重复分配整环简化副本。真实微小岛、点接触分离区、零总面积但非共线轮廓仍保留。
- Java 17、21、25 分别验证几何 33 项、轮廓 8 项、定位 11 项、定位状态 5 项；新失败回归均先在旧实现确认红灯。
- 连续 500 组、20000 笔填充／优化探针未留下新洞，闭包最多执行两轮。观测到的极小 Java2D 差集舍入在原单轮实现中已经存在，未据此引入任何面积容差。
- 两套真实 UI 定位代码的独立执行覆盖绘制、平移、滑块拖动等待，错误维度等待，单次取景，用户平移保持，撤销清标记，切换画布重新定位。Xaero 的凹轮廓在高倍率下标记精确居中，网格仍显示完整范围。
- 11 种语言全部更新位置提示并通过键集／占位符检查；modern 继续共享根目录资源。
- 完整构建命令：`.\gradlew.bat --gradle-user-home .gradle-home '-Dorg.gradle.java.home=J:/mc/jdk25' '-Pmod_version=4.8.5-editviz.2' build --offline --no-parallel --no-daemon --console=plain`。12 个版本全部成功，耗时 3 分 14 秒，2450 项测试零失败、错误或跳过。
- 核验 1.20.1 产物 `fabric.mod.json` 的版本确为 `4.8.5-editviz.2`，包含定位类及全部 11 种语言的位置提示。相关几何源码和测试在根目录与 modern 内容一致，`git diff --check` 和独立审查通过。
- 未重启、覆盖或保存用户当前游戏草稿；当前游戏仍运行旧版客户端，完整实机复测需加载新修复包。
