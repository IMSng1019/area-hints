# editviz 边界笔设计

用户已确认并要求实现（2026-11-16）。

边界笔用于涂抹域名面积：鼠标中心未越过智能限制线时，裁掉笔刷外沿越界部分；鼠标中心明确越过自然限制线时，继续涂抹，以到原岸线的距离更新局部限制线。域名边界不允许此偏移扩展。

河岸优先选择靠近当前编辑域名已有面积的一侧，没有依据或双岸都有面积时按落笔位置选择。选定后锁岸，避免在河心、岔口或越过对岸时跳岸。偏移只影响实际经过的局部岸段，可跨笔画沿用，随撤销重做恢复，切换域名后清空。

只裁剪新增笔画，既有面积保持不变。上级域名及当前维度同级域名提供矢量限制；自然边界通过地表水陆数据提取。Xaero 已探索的远处地图纳入支持范围，缺失的数据不能视作陆地或制造假岸线。未识别地形时显示状态，域名限制仍有效。

预览显示正在使用的限制线及偏移。保存前保护边界约束，继续遵守现有一位小数、单个无洞多边形和权限要求；无法同时满足时保留草稿并说明失败，不静默越界。

实现覆盖旧版共享 src、现代版 modern/src，以及全部12个版本桥接；全部11种翻译同步更新。验证包括几何测试、多版本编译构建、翻译检查、独立代码审查。游戏内交互若未执行须如实记录。
