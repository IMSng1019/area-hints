# 投稿标题

我让 MC 里的提瓦特，走到哪就显示哪里的名字｜Areas Hint 域名模组

## 简介

刚才哪一步，算进了璃月港？我给 Minecraft 做了个域名模组。走进璃月港，屏幕会报出地名。到了风起地，还能翻开地图作者留下的一页故事。

这次我在普通村庄实录了一遍：起名、绕村记下 27 个顶点，再按下保存。后半段换回方块提瓦特，拿真实的主世界域名文件算一遍，看看模组怎么从九千多个顶点里找到风起地。

如果是你的地图，你想先给哪个地方起个名字？

模组作者　IMSng

模组下载　[Areas Hint · Modrinth](https://modrinth.com/mod/area-hints)

实机与域名数据　方块提瓦特、普通村庄与层级测试世界

世界地图联动　Xaero’s World Map

声音　普通话合成旁白，本片原创器乐与游戏实录
