# 投稿标题

我给 MC 里的提瓦特加了地名提示，走两步就到璃月港｜Area Hints

## 简介

沿着这条石板路往前走，屏幕上突然冒出“璃月港”三个字。刚才哪一步算进了城？我做的 Area Hints 就管这件事。到了风起地，还能翻开一本书，看看地图作者给那棵大橡树写了什么。

想给自己的地图也加上地名，可以从 01:02 那个村子看起。我沿着房子绕了一圈，一共记了 27 个拐点。颜色选好，按下保存，“村庄”就跳出来了。

后半段用的是方块提瓦特的主世界文件。全图有 9,041 个一级顶点，我挑了风起地树下的一个坐标来算。蒙德、风啸山坡、风起地，加在一起，这次实际检查了 356 条边。

换成你的存档，你最想在哪儿看见地名跳出来？
