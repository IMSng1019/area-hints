# 域名切换音效设计

## 目标

为客户端增加可选的域名切换提示音。默认不播放声音；玩家可以从配置面板、`/areahint replacesoundevent` 客户端指令或指令可视化面板选择声音。声音来源为客户端声音注册表中的全部 `SoundEvent`，包括其他模组注册的声音；音符盒声音额外提供全部乐器和 25 个原版音阶。

## 总体方案

功能完全在客户端实现。`/areahint replacesoundevent` 使用 Fabric 客户端指令，不增加服务端命令节点、权限节点、网络包或文件读写。普通指令使用与 EasyAdd 相同风格的聊天按钮流程；指令可视化和配置面板使用可滚动的图形选择界面。

新增独立的 `soundevent` 客户端功能包，集中管理声音目录、自动分类、聊天交互、图形界面、试听、配置保存和域名状态追踪。声音目录首次打开选择界面时从 `Registries.SOUND_EVENT` 构建并缓存，域名检测循环不会遍历注册表。

## 配置模型

现有 `ConfigData` 增加以下个人客户端配置：

- `soundEvent`：声音事件的命名空间 ID，`none` 表示不播放，默认值为 `none`。
- `soundPitch`：播放音高，普通声音固定为 `1.0`，音符盒使用原版 25 音阶对应的 `0.5–2.0` 音高。

旧配置缺少字段时由 `FileManager` 补入默认值；配置复制、配置面板草稿、重置和保存均保留这两个字段。声音 ID 在客户端播放前再向注册表校验，以便支持只存在于客户端的模组声音。

## 声音目录与分类

目录读取客户端全部已注册声音，并按声音 ID 路径自动分为以下类别：

- 音符盒
- 环境与天气
- 方块
- 实体
- 物品
- 音乐与唱片
- 界面
- 事件与粒子
- 其他

已知路径前缀进入对应类别，未知前缀进入“其他”，因此不会遗漏其他模组的声音。音符盒声音识别 `block.note_block.*` 路径，先按乐器展示，再为每种乐器生成音阶 0–24；音高使用原版公式 `2^((note - 12) / 12)`。

动态声音通常没有可稳定取得的多语言显示名称，因此声音按钮显示完整注册表 ID，并通过点击试听帮助玩家辨认。分类、按钮、提示、状态和错误文本在现有全部语言文件中分别翻译。

## 普通指令交互

`/areahint replacesoundevent` 在客户端打开聊天交互：

1. 显示当前选择、“无声音”和所有非空分类按钮。
2. 点击普通分类后分页显示声音按钮。
3. 点击音符盒分类后先选择乐器，再分页显示 25 个音阶按钮。
4. 每个声音或音阶对应一个独立按钮；悬停显示 ID、分类和音高。
5. 点击声音后立即在客户端试听、写入个人配置并显示成功提示。
6. 每页提供上一页、下一页、返回分类和取消按钮。

分类、翻页和选择子指令同样由客户端命令分派器处理，聊天按钮不会向服务端发送命令。

## 图形界面交互

指令可视化注册表新增 `replacesoundevent` 项。图形流程显示“分类 → 声音”可滚动界面；音符盒增加乐器选择层。每个声音使用独立按钮，点击后试听并选择。

配置面板增加域名切换音效设置项并复用同一图形选择器。从配置面板打开时，选择结果只写入 `ConfigData` 草稿，返回配置面板后仍需点击“完成”才持久化；取消配置面板不会修改当前设置。指令与指令可视化入口则在选择后立即保存。

## 域名变化与播放

播放状态使用唯一的当前域名键：

- 玩家位于普通域名时：`维度 ID + 普通域名名称`。
- 玩家不在普通域名时：当前维度域名，即 `维度 ID`。

域名检测发布结果后，将新键与上一次键比较。只有键发生变化才播放一次，因此异步检测的重复结果不会重复播放。

- 登录世界：播放一次当前普通域名或维度域名声音。
- 普通域名与维度域名互相切换：播放一次。
- 从普通域名 A 直接进入 B：播放一次。
- 切换维度：播放一次新维度中的当前域名声音。
- 断开服务器：只静默清理状态，不播放。
- 模组整体关闭：不播放并静默清理状态；重新开启后首次有效判定播放一次。

播放音量固定为 `1.0`，遵循 Minecraft 主音量和玩家音效音量。配置的声音 ID 不再存在时跳过播放，只对该 ID 记录一次警告并保留配置，使对应模组重新安装后能够自动恢复。

## 性能与兼容性

- 服务端完全不参与该功能。
- 声音注册表只在首次使用选择器时扫描并缓存。
- 每次域名检测仅增加一次常量时间的状态键比较；只有变化时才查询声音并播放。
- 不修改域名 JSON、维度域名数据、服务端协议或现有日志消息。
- 动态注册表使新加入的原版或模组声音无需修改代码即可出现。

## 验证

遵照仓库要求不新增测试文件。实现后运行 Gradle 完整构建、Git 差异检查和 JSON 解析检查，并人工核对以下场景：默认无声音、普通声音选择与试听、各音符盒乐器和 25 音阶、登录世界、普通域名进出、A 到 B、维度切换、模组开关以及已配置声音缺失。
