## 人工验收清单

以下项目需要实际进入游戏验证；自动构建不能代替这些验证。

1. 在未安装 Xaero 的客户端执行 `/areahint editviz`，确认打开网格画布；安装兼容 Xaero 后默认打开地形画布。绘制一笔、修改属性、撤销、切换画布，再重做，确认草稿和历史保留。
2. 分别用选区笔、直线、矩形、椭圆、橡皮和魔棒绘图，调整粗细并按住 Shift；魔棒点开放区域应提示失败，不能填满整张地图。对已有小数坐标、斜边域名只增添局部笔画，检查其余边不移动。
3. 尝试产生洞、分离岛屿、自交和超限坐标；保存应显示原因并保留草稿。恢复为有效单环后可以继续保存。
4. 以多个 GUI 比例、不同窗口尺寸和地图缩放操作；测试工具栏、属性输入、滚动树、空格拖动和地图缩放，确认输入不会同时触发地图菜单或画布绘制。
5. 在主世界、下界、末地检验地图上方块坐标与实际位置一致。切换 Xaero 所查看的维度时不得编辑非当前玩家维度。
6. 检查搜索、折叠和维度根节点；新建、重命名、联合域名、颜色、高度及高于三级的等级均可编辑。整棵子树改级后每级关系正确，改名后直接子域名引用更新；有子域名的父域名不可删除。
7. 用普通玩家、署名玩家、扩展署名玩家、上级署名玩家和 OP 分别验证权限；显式拒绝对应节点后操作失败。边界同时增减必须同时具备 expandarea 和 shrinkarea 权限。
8. 两名玩家同时编辑同一目标或子树，后提交者应收到冲突并保留草稿；修改无关域名不应阻止另一草稿保存。
9. 开启审批，提交新建、修改、删除及改名改级申请，确认正式域名在批准前不变。详情应显示修改前后内容和后代；打回后恢复同目标、同操作，修改重提时重新校验权限和基线。
10. 模拟响应延迟或超时，草稿保留；收到明确成功后才退出。退出/切换目标有保存、放弃、继续编辑选择。断线、换服务器或切维度使旧会话失效。
11. 重启服务端验证已批准数据、审批状态与事务恢复；集成服务端和独立服务端均执行一遍，并检查其他在线客户端同步。
12. 切换全部 11 种模组语言，检查按钮、帮助、错误和审批类型均无原始翻译键、占位符错误或截断重要操作。

## 实现边界

沿用现有主世界、下界、末地存储，不新增自定义维度文件映射。提交及正式文件同步限制为 8000000 字符；旧客户端不接收新的大型文件分片。新建、改名不能占用维度 ID 或维度显示名，避免普通域名遮蔽特殊根节点。魔棒仅使用当前画布附近的完整参考边界，并有求交与绘制资源限制；超过限制会保留草稿并提示缩小操作范围。
