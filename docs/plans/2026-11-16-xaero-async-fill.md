# Xaero 域名进入填充性能修复

**目标：** 多顶点域名进入时不再在地图渲染线程同步裁剪父域名，并减少无效几何碎片和重复计算。

**已确认方案：** 用户已同意采用无效切割排除、专用后台线程和结果缓存；直接在 main 实施并提交，不创建 worktree。

## 设计

- 纯 Java `TriangleMeshDifference` 承载原有三角网格差集，先做包围盒和凸多边形分离轴排除，避免没有交集的片段被延长线反复切碎；保留现有填充和父子层级语义。
- `AsyncOverlayCache` 使用外部专用单线程执行器，每个维度只保留最新请求，计算在锁外进行；计算内部检查取消状态。发布前验证请求及清理代次，旧结果不能覆盖新状态。
- 几何缓存键只依赖快照版本、维度和当前域名，不依赖每次进出递增的检测版本；使用有上限的最近使用缓存。
- `AreaOverlayRepository` 在快照建立时转换一次基础填充网格。渲染入口只提交请求和读取已完成计划，计算未完成时使用同一快照的基础填充，避免展示其他世界或过期快照的结果。
- 仅当前域名及其有效祖先需要特殊填充；其它域名复用基础网格。新快照和断连清理使后台旧请求失效。
- 保持 OpenGL、GPU、Minecraft 世界对象访问在原线程；后台只处理不可变几何快照。不修改 JSON、翻译、检测规则或游戏模式功能。
- 共享旧版和 modern 源码分别同步，覆盖 settings.gradle 中全部 12 个版本。

## 实施与验证顺序

1. 在 `src/test/java/areahint/geometry/TriangleMeshDifferenceTest.java` 添加面积、点覆盖、相切、共边、绕序、无交集伪切割、多顶点输出规模和取消回归，先验证失败，再实现几何工具；同步 modern。
2. 在 `src/test/java/areahint/xaero/AsyncOverlayCacheTest.java` 添加可控执行器测试，覆盖非阻塞提交、只保留最新请求、维度隔离、重访缓存、失效、错误与容量限制，再实现调度器；同步 modern。
3. 接入 `AreaOverlayFillResolver` 和 `AreaOverlayRepository`；基础网格只转换一次，渲染入口不等待，刷新/清理取消过期工作。
4. 使用已有 JUnit 和 Gradle 配置运行基线与 modern 测试，再执行全部版本 build；进行独立代码审查和差异检查。
5. 重跑四顶点父域名与多顶点子域名的纯几何探针，记录耗时及输出规模。测试只以几何正确性和结构规模作断言，不使用不稳定的耗时硬阈值。
6. 记录验证结果并提交本次文件。游戏内实际帧时间和地图显示需要人工实机复核，不能由编译或合成探针替代。

## 验证结果

- 新增 26 项 JUnit 回归（几何 13 项、后台缓存 13 项），同步旧版和 modern；已完成先失败后通过的回归验证。
- `python -X utf8 tools/test_xaero_async_fill.py`：旧版、modern 各 13 项真实客户端源码集成测试通过。占住后台执行器时 `resolve` 仍立即返回；父链、重访、同名新快照和断连清理行为符合设计。`--source-ref 2d9dd14` 对修复前源码正常编译、按预期断言失败。
- 基线与现代节点命令 `./gradlew.bat -Porg.gradle.java.installations.paths=J:/mc/jdk25 :1.20.4:test :1.20.4:compileClientJava :modern:26.3:test :modern:26.3:compileClientJava --no-parallel --no-daemon --console=plain` 通过。
- 全版本命令 `./gradlew.bat -Porg.gradle.java.installations.paths=J:/mc/jdk25 test build --no-parallel --no-daemon --console=plain` 通过，12 个节点均完成构建。首次运行在打包时被沙箱临时目录权限阻止，经批准在沙箱外执行同一命令后成功。
- 全版本 JUnit 报告合计 1,718 项执行，失败、错误和跳过均为 0；1.20.1 至 1.21.10 各 140 项，1.21.11 为 144 项，26.1.2 / 26.2 各 150 项，26.3 为 154 项。
- 独立代码审查未发现阻断问题，旧版与 modern 几何、调度、测试及仓库实现一致，解析器仅 Minecraft 映射名称不同。
- 固定四顶点父矩形、半径 100 的圆形子域名，20 次小规模预热后各测量 5 次；生产几何实现的 128 / 512 / 1024 顶点中位耗时约为 2.0 / 17.3 / 50.4 毫秒，输出为 598 / 2,166 / 4,837 个三角形。修复前 512 顶点约 2.9 秒、183,946 个三角形。此处为合成探针，不代表游戏帧时间。
- 另用独立 `java.awt.geom.Area` 对照 2,000 组固定种子随机三角遮罩，差集覆盖与面积一致，最大面积误差约 5.68e-14。
- 尚未进行游戏内目视和帧时间实测。首次进入且后台尚未完成时显示同一快照的完整基础填充，随后切换为正确挖空结果。
