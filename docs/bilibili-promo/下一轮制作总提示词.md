## 启动口令

## 导演任务

为 Minecraft 域名模组 Areas Hint 制作一支面向 B 站地图作者、建筑服和 RPG 服主的推广片。观众看完应能回答三个问题：“玩家走进去会看见什么？”“我怎么给自己的村庄划界？”“提瓦特有九千多个边界点，为什么找到风起地只需精查少数区域？”以第一人称作者视角讲，把答案落在真实的游戏反馈上。

总长 **03:26，206 秒，12,360 帧**。主序列 1920 × 1080、16:9、恒定 60 fps、Rec.709、48 kHz。成片计时从零开始。下表的“源”都指已命名的 PR 子序列从零起的秒数。所有时间区间前含后不含。精剪可在同一镜内微调，保留段尾时间和读字停顿。

PR 负责总剪、音轨、字幕与交付。Remotion 负责脚印越界、内嵌实机、轮廓与射线、真实 JSON 地图、截图运镜。优先用实机截图做封面。AE、Blender、SD 和 ComfyUI 只在确定有镜头需要时使用。参考片取其固定窗口、由示意切到结果以及短标题的手法；所有入片像素、配乐和品牌包装使用本片素材。

## Remotion 动画提示词

制作可以单独渲染、在 PR 中替换的合成。按上表时间制作，嵌入视频时明确用子序列时间映射，取真实动作相邻的帧。让玩家点、字幕、截图地名在进入和离开合成时保持视线连贯。

1. **脚印与片名。** 从实机石路取暖灰色，从描述书取纸色，墨绿画出区域线，金色表示玩家。三个脚印按行进节奏落下，第三个落在线内，停 12 帧再显片名。标题从静止画面中进入，片名与实机跳字各自占一个阅读时刻。
2. **城区与街区。** 画一个易辨认的外城、街巷和内街区。左边约占三分之二，右边只保留当前问题。父域名先亮，子域名随后出现；同一窗口替换为真实的超平坦测试世界。参照窗口四角与中轴对齐，保留原画幅，给真实 HUD 足够面积。
3. **录点窗口。** 用三张真实帧做快速总览，展开放大当前步骤。命令、名字和取点计数均取自原生 UI；1080p 下可以用局部放大补充读数。首次按键用一声轻敲配原反馈。三词导航只出现在作者操作段。
4. **判定原理。** 设水平轴为 +X，垂直轴为 Z。例如依序连接 (0,0)、(10,0)、(10,8)、(4,8)、(4,3)、(0,3)，形成凹多边形。从 (2,5) 向右发射线，应在 X=4、10 产生两个交点；把玩家移到 (6,5)，只剩 X=10。动画从曲线的几何计算得出交点与计数。用实心点标玩家、圆环标交点、虚线标包围盒，颜色外再给一层形状区别。左下角标“边界示意”。
5. **真实地图与性能。** 按同一比例把输入数据的 X/Z 投影到平面上，轮廓用各域名的 `vertices` 闭合。检查轴向，让蒙德和璃月的相对位置与截图一致。按层淡入 6 个一级、20 个二级、56 个三级域名；总计 9,041 个一级顶点，另有 328 个辅助包围盒顶点。示例点按客户端范围、高度、候选顺序与父子链复核。预筛允许多个候选，只有实际调用点在多边形内判定时才记作精查。图上保留原始坐标关系，精查数值限定为本示例。若原 JSON 在开工时已更新，重新计算并同步旁白、字幕、图形数字。
6. **地图联动。** 读取原始 PNG。移动图像裁切框，让风起地文字在叠化两端对齐，过渡约 15 帧；先松开视野，再由截图右上移向下部的璃月港。到达后停稳再切实机。多级填色、地名保持原图像素。小地图联动可在原录屏有清楚叠加的情况下短暂指出。
7. **片尾。** 使用同一棵风起地大树的实机帧，压暗排字区域，留住光柱与树冠。落模组名、作者、下载提示。地图作者和正式作品名已有可靠署名时加入发布简介，保留作者原署名拼写。

## 声音、字幕、封面与发布文案提示词

**旁白。** 用自然普通话，像地图作者坐在朋友旁边，边操作边解释。第一句轻，问句有真实好奇；第一次出现“璃月港”、第一次记录成功和保存后跳字都允许静默。数字读慢半拍，“九千多个”用于口语，9,041 用于画面。先试读“璃月港、提瓦特、风啸山坡、Areas Hint、Xaero”，选能读清的一版。旧 185 秒文案按新剪辑重新分句。交付 48 kHz 独立旁白轨。

**音乐与音效。** 做一条可发布的原创或已取得使用权的纯器乐。轻木质拨弦、松散拍点与低音长音贯穿全片，片头先有脚步再进音乐，第 27 个点后给原理动画留空间，保存前抽掉节拍，在地图拉远时带回旋律。独听原工程六条录音轨，选干净游戏声。交点两声使用同一个轻音色。先按人声定平衡，配乐低约 10–14 dB 起调，成片约 −16 LUFS-I、真峰值 ≤ −1 dBTP 作为试听目标。片尾保留自然衰减。

**字幕与排版。** 中文标点自然，按意群断句，每条最多两行，手机横屏能一眼读完。中文首选思源黑体，书页引句可用思源宋体，机器缺字时选覆盖完整的中文字体。1080p 字幕从 46–50 px 试排；数据数字更大，说明短一点。用浅描边或柔和衬底，在聊天栏、域名标题、书页、地图标签出现时移动字幕到画面空白处。按最终音轨输出 UTF-8 SRT。

**封面。** 用《进入璃月港》源约 8 秒原帧，保留海湾、港口轮廓、像素建筑和实机“璃月港”。在留白处排“走进璃月港”，旁边小字“自制 MC 域名模组”。如两组同名文字争视线，将封面大字改成“MC 也能报地名”。缩小到首页预览大小，仍要能认出游戏和标题。

**投稿标题。** 我让 MC 里的提瓦特，走到哪就显示哪里的名字｜Areas Hint 域名模组

**简介草稿。** 走进璃月港，屏幕会报出你到了哪里；来到风起地，还能读到地图作者写下的一页故事。我用一个普通村庄演示了从起名、划边界到保存的全过程，也拿方块提瓦特的真实域名数据，带你看看模组怎么在九千多个顶点里找到风起地。你最想先给自己地图里的哪里起名？模组作者 IMSng。模组下载见 [Modrinth 项目页](https://modrinth.com/mod/area-hints)。地图与音乐按实际来源署名。

## 总剪、验收与交付提示词

- 先确认 PR 当前连接和源媒体位置，在独立工程建立 206 秒主序列，按表打章节标记。PR 中保留可修剪的实机片段、独立 Remotion 合成、可编辑字幕，以及游戏声、音乐、旁白三类音轨。旧缓存、旧 XML 与旧配乐按新时长核对。生成的新媒体放到固定媒体目录，方便工程重开。
