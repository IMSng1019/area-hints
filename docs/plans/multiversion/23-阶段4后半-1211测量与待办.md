# 23 · 阶段 4 后半：1.21.1 测量结果与待办（2026-10-03）

> 目标：判断 1.21.1 能否像 1.20.6 一样直接打开。结论：**服务端已经通了，客户端还差渲染整代重写**，本轮不激活。

把 `deps.1.21.1.skeleton` 临时改成 `false`，并把 1.20.6 代际的实现复制进 1.21.1 版本目录
（`versions/1.21.1/src/{main,client}/java/areahint/network/` 与 `.../description/BookStackFactory.java`），然后编译。

## 二、结果

| 项 | 结果 |

| `src/main` | **0 错误**（只有 1 处机械改名：1.21 起 `Identifier` 构造器私有化，`new Identifier(ns, path)` → `Identifier.of(ns, path)`，已修在 `versions/1.21.1` 的实现里） |

## 三、客户端 48 处错误分三类

### 类别 1：`HudRenderCallback` 回调参数（8 处 / 4 文件）——**已修完**

```
CPURender.java:85 / GLRender.java:63 / VulkanRender.java:61 / EasyAddRecordingHud.java:26
  不兼容的类型: RenderTickCounter 无法转换为 float
```
1.21.1 的回调是 `(DrawContext, RenderTickCounter)`，1.20.4 是 `(DrawContext, float)`。
**该参数在本模组 4 个回调里全都没用到**（22 号文档已实测：frameDelta 0 调用点），所以只要把方法签名按版本分支即可。
**已落地**：`CPURender` / `GLRender` / `VulkanRender` / `EasyAddRecordingHud` 各加一个 `//? if >=1.21` 条件块（`<=1.20.4` 侧保持 float、`>=1.21` 侧用 `RenderTickCounter`），注册处的写法两版通用、不用动。
实测：1.21.1 客户端错误由 ~93 条降到 **44 条**，这 4 个文件不再报错；1.20.4 侧编译不受影响。

### 类别 2：`Tessellator.getBuffer()` 被移除（70 处 / 2 文件）——**1.21 渲染整代重写**

```
boundviz/BoundVizRenderer.java      52 处（tessellator.getBuffer()、BufferBuilder 系列）
xaero/OverlayRenderHelper.java      18 处（Tessellator.getInstance().getBuffer()）
```
1.21 起立即模式渲染管线整体换成 `BufferRenderer` / `RenderSystem.getDevice()` 那一套。
这正是 05 号文档说的「渲染整代重写」，**必须走 RenderHost 抽象 + 版本侧实现**，不能靠几行条件注释。

### 类别 3：Xaero 世界地图 API 漂移（3 文件）——第三方隔离（阶段 6）

```
xaero/worldmap/XaeroWorldMapBridge.java:37     Screen 无法转换为 GuiMap
xaero/worldmap/AreaWorldMapRightClick.java:96  不可比较的类型: Screen 和 GuiMap
```
新版 Xaero（`fabric-1.21.1-1.46.0`）里 `GuiMap` **不再继承 `Screen`**，而我们的兼容层假设它继承。
若改用旧命名世代的 `1.40.2_Fabric_1.21` 又会缺 `CursorBox`（与 1.20.1 同一个坑）。
→ 1.21.1 的 Xaero 坐标需要重新选一个同时满足 `CursorBox` 与 `GuiMap extends Screen` 的版本，或者按阶段 6 把兼容层隔离到版本侧。

## 四、本轮的处理与保留物

- **1.21.1 仍为骨架**（`deps.1.21.1.skeleton=true`），默认 `gradlew build` 保持全绿。
- `versions/1.21.1/src/**` 的代际实现**保留**：已实测 `src/main` 可编译，是下一轮打开 1.21.1 的起点（骨架模式下这些文件不参与编译，无副作用）。
- `deps.1.21.1.xaero_world_map` 暂时写成 `fabric-1.21.1-1.46.0`（能解决 CursorBox，但会引入类别 3），下一轮要重新定夺。
