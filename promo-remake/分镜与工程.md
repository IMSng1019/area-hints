## 素材与声音

实机与地图来自 `J:\素材`。[跳字图片](public/titles/) 从第三人称入港与多级跳字录屏中提取，璃月港字样的阴影按实拍偏移重建。地图团队和分镜、摄影个人名单未随大纲提供。片尾用“创作团队”统称分镜与录制，并注明场景“方块提瓦特”；模组作者 IMSng 和 MIT 许可来自模组清单。

[本片配乐与动作音](public/score.m4a) 按此时间线编排，包含脚步、跳字、同步、跨界与落标声。实机剪辑去除了原录音，人物配音轨为零。

## 继续剪辑

在 `promo-remake` 目录运行。Git 保存合成源码、字图、地图图像、配乐和剪辑脚本。输出和较大的实拍中间片保存在本机。

```powershell
npm ci
python scripts/prepare_clips.py 'J:\素材'
npm start
```

本机已备好素材和依赖，可直接运行 `npm start` 打开 Studio，或运行 `npm run render` 导出至 `out/Area-Hints.mp4`。重新生成剪辑需要 FFmpeg，可用环境变量 `FFMPEG` 指定可执行文件。选取 `Area-Hints` 编辑全片，选取 `Mechanism` 单独检查机制段。
