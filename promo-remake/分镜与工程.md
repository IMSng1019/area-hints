## 四格编辑动画

| 指令 | 四格里要看哪里 |
| --- | --- |
| `/areahint easyadd` | 从空地开始，用绑定键依次记录顶点，完成后形成一个新域名。 |
| `/areahint expandarea` | 对照新线与原边界，向外补入一块面积。 |
| `/areahint shrinkarea` | 新线向原范围内弯入，切去的部分和保留的部分分开显示。 |
| `/areahint dividearea` | 分割线穿过原域名，两侧形成分别配置的两个域名。 |

四种操作使用简化的几何示例。录像里的璃月港、域名创建界面和地图联动使用团队提供的实机素材。

## 素材与署名

实机与地图来自 `J:\素材`。[四张跳字](public/titles/) 从第三人称入港与多级跳字录屏中提取，璃月港的阴影按实拍偏移重建。红石用途采用电路示意。片尾用“创作团队”统称分镜与录制，实机场景写作“方块提瓦特”。模组作者 IMSng 和代码许可 MIT 来自模组清单。

[本片声音](public/score.m4a) 按新版镜头重排，包含器乐、脚步、跳字、录点、同步和跨界提示。

## 继续剪辑

本机在 `promo-remake` 目录运行 `npm start` 可打开 Studio，选 `Area-Hints` 编辑整片，选 `Editing-Tools` 或 `Mechanism` 可分别预览两个动画段。`npm run render` 导出到 `out/Area-Hints-v2.mp4`。

在新环境中，先用 `npm ci` 安装依赖，再运行 `python scripts/prepare_clips.py 'J:\素材'` 生成较大的实机中间片。可用环境变量 `FFMPEG` 指定 FFmpeg 的路径。Git 保存合成源码、跳字、地图图像、配乐和制作脚本。
