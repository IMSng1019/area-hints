## 结构说明

- 默认按**一支 3:26 主片**做：PART 0 钩子 → PART 1 实际演示 → PART 2 操作流程 → 结尾。
- 如果你想把两段拆成两条视频：A 片用 PART 0 + PART 1 + 结尾前半；B 片用 PART 2 + 结尾后半；分镜表已按段落标好，直接拆即可。

## 三个硬约束

1. **所有模组 UI 必须真实**：实机屏幕录制或 ReplayMod 实拍；AI 只做白色背景、纸张、抽象图形、封面底图，**绝不生成聊天框、按钮、地图界面**。
2. **转场优先蒙版**：圆角窗口、多边形边界、文字遮罩、纸页擦除、亮度蒙版、分屏；不依赖第三方插件也能完成。
3. **AI 合规**：本片使用 AI 画面、AI 配音、AI 封面时，B 站投稿必须勾选「该视频使用人工智能合成技术」；片内标识持续 ≥2 秒、文字高度 ≥画面最短边 5%；简介第一行说明。

## 还没定、需要你补的

- 测试世界/服务器里王都、王座厅、矿城、下界点的实际坐标与建筑名。
- 审批镜头是否能用两个账号同时录；不能用就拆成两段录。
- Xaero 精确版本是否已对齐（1.20.4：Minimap 25.2.0 / World Map 1.39.2）。
- ReplayMod 渲染是否会把模组标题一起录进去；先做 10 秒测试，不行就用 AE 叠加（见 05）。
- BlueMap 是否已搭好；没有就删掉对应镜头。
